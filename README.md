# Emby 路径反向代理

一个基于 Go 开发的 Emby 路径反向代理服务，集成 Web 管理后台、访问统计、流量监控、IP 地区识别、访问规则控制和数据上报等功能。

无需单独部署 Nginx，即可通过 URL 路径指定目标地址，实现灵活的反向代理。

## ✨ 主要功能

### 1. 路径反向代理
- 通过 URL 路径指定代理目标，无需提前配置固定的上游地址。
- 支持 HTTP / HTTPS 自动识别。
- 根据目标端口自动判断连接协议。
- 支持自定义目标路径及请求参数。
- 支持 WebSocket 代理。
- 支持 Emby 等服务的访问转发。

### 2. Web 管理后台
- 独立的 Web 管理界面。
- 用户名、密码登录验证。
- 验证码登录保护。
- 支持修改管理配置。
- 支持限制管理后台访问 IP。
- 支持操作记录审计。

### 3. 访问统计
- 今日请求数量。
- 累计请求数量。
- 上传和下载流量统计。
- IP 访问次数统计。
- 国家及地区访问统计。
- 访问域名统计。
- 客户端类型及 User-Agent 统计。
- 每日、每小时数据统计。
- 实时访问记录及并发连接监控。

### 4. 网络流量监控
- 实时上传速度。
- 实时下载速度。
- 实时并发连接数。
- 实时请求速率。
- IP 上传和下载流量统计。

### 5. 访问安全控制
- 中国大陆 IP 访问限制。
- IP 黑名单，支持单个 IP 和 CIDR 网段。
- User-Agent 白名单。
- 目标域名白名单。
- 管理后台独立 IP 白名单。
- 访问拦截记录。
- 访问规则在线测试，可提前判断请求是否会被放行。

### 6. 数据上报与通知
- 支持定时统计数据上报。
- 支持自定义上报地址。
- 支持 Bearer Token。
- 支持节点名称及备注。
- 支持昨日访问日报。
- 支持自定义日报模板。
- 支持独立设置日报推送地址和 Token。

### 7. 其他功能
- 独立测速链接生成。
- 测速链接有效期及使用次数限制。
- 数据库备份与恢复。
- 配置导入与导出。
- 历史统计数据管理。
- systemd 服务管理。
- 自动清理临时构建文件。

## 🖥️ 环境要求

- Linux 系统
- systemd
- root 权限
- Go 1.20 或更高版本（安装脚本可自动安装）
- 网络连接，用于下载 Go 及编译依赖

## 🚀 安装方法

使用项目提供的一键安装脚本。

```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/SunMoonWithYou/emby_rp_vps_go/main/install.sh)
```

首次运行会进入安装菜单，可以选择：

1. 设置服务端口。
2. 设置管理员密码。
3. 确认安装。

默认配置：

| 项目 | 默认值 |
|---|---|
| 服务名称 | emby-proxy |
| 服务端口 | 8520 |
| 管理员用户名 | admin |
| 管理后台 | http://服务器IP:8520/admin/ |
| 配置目录 | /etc/emby-proxy |
| 数据库 | /etc/emby-proxy/emby.db |

注意：`install.sh` 请替换为仓库中实际的安装脚本文件名。

## 📖 使用说明

### 管理后台

安装完成后，在浏览器打开：

```text
http://服务器IP:8520/admin/
```

使用安装时设置的管理员账号和密码登录。

### 反向代理使用

代理请求采用路径指定目标地址的方式。

基本格式：

```text
https://你的代理域名/https://目标服务器域名/路径
```

例如：

```text
https://proxy.example.com/https://emby.example.com:8920/
```

访问该地址即可将请求转发到指定的目标服务器。

目标端口协议识别规则：

- 443、8443、8920、9443：默认 HTTPS。
- 80、8080、8000、8081、8090 等常见 HTTP 端口：默认 HTTP。
- 其他端口：默认 HTTPS。
- 也可以在路径中明确指定 HTTP 或 HTTPS。

## ⚙️ 命令行管理

安装脚本支持以下命令：

| 命令 | 功能 |
|---|---|
| `menu` | 打开管理菜单 |
| `install` | 安装或重新安装 |
| `update` | 更新程序 |
| `uninstall` | 卸载程序 |
| `status` | 查看运行状态 |
| `start` | 启动服务 |
| `stop` | 停止服务 |
| `restart` | 重启服务 |
| `help` | 查看帮助 |

例如：

```bash
sudo bash install.sh menu
```

查看运行状态：

```bash
sudo bash install.sh status
```

更新程序：

```bash
sudo bash install.sh update
```

重启服务：

```bash
sudo bash install.sh restart
```

## 🔧 配置与数据

程序默认使用以下目录：

```text
/etc/emby-proxy/
├── emby.db
└── build.sha256
```

其中：

- `emby.db`：保存管理配置、统计数据及相关记录。
- `build.sha256`：保存程序构建校验信息。

建议定期通过管理后台备份数据库，避免意外操作造成数据丢失。

## ⚠️ 注意事项

1. 请确保服务器防火墙及云服务器安全组已放行对应服务端口。
2. 建议通过 HTTPS 访问管理后台，不要直接将管理后台暴露在不可信网络中。
3. 请妥善保管管理员账号和密码。
4. 配置 IP 白名单时，请确认自己的管理 IP 已被允许，避免无法访问后台。
5. 卸载操作会删除程序、配置、管理员密码和统计数据，请提前备份。
6. 代理目标地址应当是自己拥有或获得授权访问的服务。
